# StandBy GFX

Broadcast graphics engine: Preview / Program, transitions, live data, outputs for OBS / vMix.
Written from the behaviour spec (vault: Codebase/Tooling/StandBy GFX/Spec 01) and opens existing GFX Baby workspaces.

    python -m sgfx --workspace <folder> [--library <folder>] [--port 7820]
    python -m unittest discover -s tests -t .
